# Настройка ТВ-табло в коридоре

## Что нужно

Телевизор (или монитор) с браузером — либо со встроенным Smart TV браузером,
либо через подключённый мини-компьютер / приставку с браузером (Chrome, Edge, Firefox).
Устройство должно быть подключено к той же локальной сети школы (Wi-Fi/LAN), что и
компьютер-сервер.

## Какой адрес открыть

Узнайте IP-адрес сервера у завуча/администратора (см. `DEPLOYMENT.md`, раздел 3),
например `192.168.1.10`. В браузере телевизора откройте один из адресов:

- **Режим «Текущий день»** (крупно, только сегодняшние уроки):

  ```
  http://192.168.1.10:3000/tv/day
  ```

- **Режим «Неделя с автопрокруткой»** (вся неделя, автоматическое перелистывание
  по классам, с указанием времени уроков):

  ```
  http://192.168.1.10:3000/tv/week
  ```

Выберите один из режимов — вешать оба сразу не нужно, если только на телевизоре
не открыты две отдельные вкладки/окна.

## Автообновление

Страница ТВ-табло сама, без участия человека, каждые 30 секунд проверяет — не
опубликовал ли завуч новую версию расписания, и обновляется автоматически. Вручную
перезагружать страницу не требуется.

## Рекомендации

- Включите в браузере телевизора полноэкранный режим (F11 на большинстве браузеров).
- Отключите на телевизоре автоматический переход в спящий режим/заставку в учебные часы.
- Если телевизор перезагрузился (например, после отключения питания), браузер должен
  сам открыть сохранённую вкладку — уточните у производителя ТВ, либо настройте
  автозапуск браузера с нужным адресом при включении устройства.
