# Инструкция по развёртыванию

Система разворачивается на одном компьютере в школе (например, компьютере завуча)
и работает полностью офлайн, без выхода в интернет. Остальные устройства (учительские
компьютеры, ТВ-табло, компьютер для печати) обращаются к этому серверу по локальной
сети школы (Wi-Fi/LAN).

> Технический стек — Node.js вместо изначально запланированного Python/FastAPI
> (см. `README.md`, раздел «Отклонение от ТЗ»). Функционально система полностью
> соответствует техническому заданию.

## 1. Установка на школьный компьютер (Windows)

1. Установите Node.js LTS (версия 20 или новее) с официального сайта nodejs.org —
   потребуется интернет один раз, только для установки. После установки интернет
   больше не нужен.
2. Скопируйте папку проекта целиком на компьютер, например в `C:\raspisanie`.
3. Откройте командную строку (PowerShell) в этой папке и выполните:

   ```bash
   npm install
   npm run build:css
   ```

   Эти две команды нужно повторить, только если изменятся файлы программы
   (например, при обновлении версии). Для повседневной работы — не требуется.

4. Запустите сервер:

   ```bash
   npm start
   ```

   При успешном запуске в окне появится строка вида
   `сервер запущен: http://localhost:3000`.

## 2. Автозапуск сервера вместе с Windows

Чтобы сайт и ТВ-табло не переставали работать после перезагрузки компьютера,
настройте автозапуск сервера при включении:

1. Создайте файл `start-server.bat` в папке проекта со следующим содержимым:

   ```bat
   @echo off
   cd /d C:\raspisanie
   npm start
   ```

2. Нажмите `Win+R`, введите `shell:startup` и нажмите Enter — откроется папка
   автозагрузки Windows.
3. Поместите в неё ярлык на `start-server.bat`.

Теперь при каждом включении компьютера сервер будет запускаться автоматически.

## 3. Как узнать адрес сервера для других устройств

На компьютере-сервере выполните `ipconfig` и найдите IPv4-адрес (например,
`192.168.1.10`). Остальные устройства в той же сети школы открывают в браузере:

```
http://192.168.1.10:3000
```

Этот адрес нужен учителям (публичный просмотр), ТВ-табло и компьютеру для печати.

## 4. Резервное копирование

Все данные хранятся в одном файле `data/schedule.db`. Чтобы сделать резервную копию,
просто скопируйте этот файл в надёжное место (например, на флешку) — например,
раз в неделю или перед крупными изменениями расписания. Для восстановления —
остановите сервер, замените файл `data/schedule.db` копией и запустите сервер снова.

## 5. Если сервер завис или не отвечает

Закройте окно с сервером (или завершите процесс `node.exe` через Диспетчер задач)
и запустите `npm start` заново (или перезагрузите компьютер — сервер запустится
автоматически, если настроен автозапуск по п. 2).
