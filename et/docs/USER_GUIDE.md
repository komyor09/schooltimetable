# Руководство пользователя для завуча

Система «Электронное расписание уроков» — МТМУ №40

## 1. Вход в систему

Откройте в браузере адрес сервера, например `http://192.168.1.10:3000` (точный адрес
даёт тот, кто устанавливал сервер — см. `DEPLOYMENT.md`). Пароль на этапе MVP не
требуется — раздел завуча открыт для любого устройства в локальной сети школы
(см. раздел «Риски» в техническом задании).

## 2. Порядок заполнения справочников

Прежде чем генерировать расписание, заполните разделы в этом порядке:

1. **Предметы** — список названий предметов.
2. **Кабинеты** — список номеров/названий кабинетов (справочно, без проверки занятости).
3. **Классы** — для каждого класса укажите параллель, смену и сетку дней/уроков
   (сколько уроков в этот день недели у этого класса; 0 — выходной для класса).
4. **Учителя** — ФИО, какие предметы ведёт, методический день (один день, когда
   учитель в школе, но без уроков) и занятые дни (если есть).
5. **Учебный план** — сколько уроков предмета в неделю положено параллели
   (одинаково для всех классов параллели).
6. **Подгруппы** (если требуется) — включите режим подгруппы для пары «класс + предмет»,
   если урок ведут два учителя одновременно с двумя половинами класса.
7. **Время уроков** — во сколько начинается и заканчивается каждый урок в каждой смене
   (нужно для отображения времени на ТВ-табло).

## 3. Генерация расписания

Откройте «Расписание (черновик)» и нажмите **«Сгенерировать»**. Система построит
черновик на неделю для всех классов, без конфликтов учителей. Черновик виден только
завучу — на сайте, ТВ-табло и в печати он не отображается.

Если систему не удалось расставить какие-то уроки автоматически (например, единственный
учитель предмета занят в единственный подходящий день), они попадут в список
**«Не удалось расставить автоматически»** — их нужно доставить вручную.

Повторное нажатие «Сгенерировать» полностью пересоздаёт черновик заново.

## 4. Ручное редактирование

В сетке черновика выберите класс, затем нажмите на любую ячейку — откроется форма,
где можно изменить предмет, учителя, кабинет, включить/выключить подгруппу для этого
конкретного урока. Система не даст сохранить урок, если выбранный учитель уже ведёт
другой урок в это же время — появится предупреждение с указанием, у какого класса
он занят.

## 5. Публикация

Когда черновик готов, нажмите **«Опубликовать»**. Расписание сразу станет видимым:

- на публичной странице просмотра;
- на ТВ-табло в коридорах (обновится автоматически, без вмешательства человека);
- доступным для печати.

До публикации зрители видят предыдущую опубликованную версию (если она была) или
пустой экран.

## 6. Просмотр и печать

Раздел **«Публичный просмотр»** — просмотр опубликованного расписания по классу или
по учителю. Раздел **«Печать»** — то же самое в печатной раскладке; кнопка «Печать»
открывает системный диалог печати браузера (там же можно сохранить в PDF).

## 7. Язык интерфейса

Переключатель **RU / TJ** в правом верхнем углу меняет язык интерфейса
(русский / тоҷикӣ). Названия классов, ФИО и предметов, которые вводит завуч,
не переводятся — это данные, а не элементы интерфейса.

## 8. Изменения в течение года

Если учитель заболел или произошла замена, откройте черновик соответствующего дня,
внесите изменения вручную и снова нажмите «Опубликовать». Отдельного механизма
«замен» в MVP нет — это штатный способ.
